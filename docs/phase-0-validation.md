## What was run

A corpus of 3 synthetic documents describing one real economic situation —
state support for domestic rare-earth separation capacity — was ingested and
driven through the whole chain: classification, Claim extraction with verified
spans, Event resolution, Process discovery, archetype and State estimation,
Bottleneck identification, Capability mapping, Asset discovery and exposure, and
adversarial critique.

It produced **4 Claims**, **2 Events** (1 document
absorbed as syndication rather than counted as an independent source),
**1 Process** across **2 revisions**, **1 binding Bottleneck**,
**2 Capabilities** in an AND requirement tree, and **2
Assets** — an equity and the commodity itself.

Two documents in the corpus are the same wire report carried by different
outlets. The Event layer collapsed them into one independent source, which is
the behaviour ontology §47 exists to require and the easiest thing in the
pipeline to get silently wrong.

## What this establishes, and what it does not

The documents are written for this test suite; the publisher names are
fictional. The model responses are scripted, so the run is deterministic and
needs no API key. **It validates the pipeline, not the agents.** Whether the
model would produce these answers unprompted is what the labelled benchmarks in
`econiq_eval.graders` measure, and they need a real provider and a dataset
larger than Phase 0 has. The report below names the provider for that reason.

## The one criterion Phase 0 does not reach

**§28.7, "Quantitatively compare Assets", is not met**, and it is not deferred
either — deferring it would be a judgement this gate has no standing to make.

The cause is a scope gap rather than a defect. PRD §28 lists Asset comparison
among the eleven MVP criteria, but `phases.txt` stops Phase 0 at *basic* Asset
discovery and exposure mapping (#12). The Asset Quant Agent and Asset Quality
Agent (agent doc §8.3, §8.4) are not in the Phase 0 issue list, so nothing
writes an `asset_quality` scorecard, so there is nothing to compare. The
`ScorecardWriter` and the score-family separation exist and are exercised by the
Process Critic, which writes Thesis Quality — the machinery is there; the agent
that would use it for Assets is not.

This is the second discrepancy of its kind found between the agent doc's
recommended MVP and the phase sequencing; the engineering handoff records the
first (the Research Quality Auditor deferred to Phases 2-3, with #16's harness
as the interim safety net). It should be resolved deliberately: either the Asset
Quant/Quality agents move into Phase 0, or §28.7 is formally reassigned to
Phase 1 alongside the Asset comparison matrix (#29). Until then the gate reports
9 of 10 in-scope criteria met and says why the tenth is not.
